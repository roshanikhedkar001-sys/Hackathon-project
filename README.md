An enterprise-grade, closed-loop multi-agent operational platform built on Google Cloud AI technologies. CibusGrid AI prevents perishable food waste and mitigates food insecurity by autonomously fusing cold-chain IoT telemetry, computer vision freshness assessment, dynamic algorithmic markdowns, and automated non-profit shelter redistribution dispatch via Google Maps Platform Routes API.

## 🏗️ Architectural Overview
- **Perception Layer**: Sentinel Telemetry Agent & Multimodal Freshness Agent (Gemini 1.5 Flash Vision).
- **Orchestration Layer**: Chief Governance Supervisor (Gemini 1.5 Pro on Vertex AI Reasoning Engine).
- **Working Memory**: Distributed Blackboard Pattern backed by Cloud Firestore real-time listeners.
- **Action Layer**: Dynamic Markdown (ESL API), Non-Profit Redistribution (Firebase Cloud Messaging), and Spatial Logistics (Google Maps Platform Routes API).
- **Data & Compliance**: BigQuery analytical lakehouse for tax deduction receipts and carbon offset verification.
